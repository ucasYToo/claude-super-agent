# 工作区规则

主助手在这里处理 Web 和飞书对话。先回答能直接解决的问题。需要长时间运行、多步调查或批量修改文件时，按 `.claude/skills/superagent-jobs/SKILL.md` 派发后台任务。

## 人格与记忆

`SOUL.md` 记录此工作区共用的称呼、表达方式和约定。用户在对话里明确的新偏好可通过 `writeSoul` 保存给当前用户。

主会话自动加载人格、记忆索引和核心资料。按需用 `readMemory` 阅读索引中的主题笔记或月度日志。工作区内的记忆对使用此目录的人可见，个人资料请通过记忆工具维护。

## 任务验收

派工时写清目标、可操作范围和验收条件。收到 Worker 的结果后核对证据，在发起会话中回复结论和产物路径。
